# 上下闻 · 深圳 AI 线下交流会

蓝金色活动展示网站，使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 本地运行

```bash
python3 -m http.server 8080
```

打开 http://localhost:8080 。也可以部署到任意静态网站托管平台。

## 功能

- 适配手机和桌面的活动介绍、地点、参加须知及活动海报
- 星光闪烁、鼠标轻移视差、滚动入场与照片浮动
- 动效开关，支持系统减少动态效果偏好
- 报名弹窗与图片下载

## 修改内容

- `index.html`：活动文案、时间、地点、海报链接
- `style.css`：蓝金配色、响应式布局和动画
- `app.js`：报名弹窗、动效开关和滚动入场
- `assets/`：活动视觉素材

开源版本用 `assets/contact-placeholder.svg` 替代微信二维码。用于真实活动前，请换成自己的联系二维码，并修改报名弹窗内容。示例活动日期及地点是原始活动资料，不代表持续开放报名。
